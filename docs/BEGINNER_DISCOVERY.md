# 初心者ガイドと銘柄の出会い

更新日：2026年10月9日

## 初心者ガイド

`GET /guide` は匿名で閲覧できます。購入場所・選び方・持ち帰り・保存・開封・開封後を6段階で掲載し、最後に空き瓶の処分を案内します。ホーム、共通ヘッダー、その他メニュー、商品詳細から開けます。目次・次の段階は通常のリンクで、JavaScriptは不要です。

商品のラベル・蔵元の最新案内を優先します。保存・開栓の一般説明と、特定商品の例、本ガイドの編集上の提案を区別します。自治体の分別方法は断定しません。

確認した出典：

- [日本酒造組合中央会の保存ガイド](https://japansake.or.jp/sake/en/basic/how-to-store-preserve-sake/)
- [獺祭の保存と飲み方](https://dassai.com/faq/)
- [蓬莱泉スパークリングの開栓案内](https://netshop.houraisen.co.jp/products/detail/82)
- [獺祭の公式取扱店](https://dassai.com/dealer/)
- [出羽桜の公式取扱店舗](https://www.dewazakura.co.jp/shop/)

## ランダムな一本と類似メジャー銘柄

ホーム表示時にカタログ全件から等確率で1件を選びます。比較候補は `src/main/resources/data/major-sake.json` で編集者が指定します。DBの銘柄名との完全一致で候補を解決するため、DB間でIDが違っても利用できます。名称変更時は設定も更新してください。登録されていない名称は候補から外れます。

メジャーは「公式商品情報と購入先案内が確認でき、定番として比較しやすい」という本サイトの編集基準です。初期候補は獺祭 純米大吟醸45、八海山 特別本醸造、出羽桜 桜花吟醸。公式情報・購入先のURL、選定理由、確認日を設定し、ホームの開閉欄で表示します。売上順位や在庫を保証する区分ではありません。

類似度は登録タグの正のスコアベクトルによるコサイン類似度です。未登録・0・負のスコアは0として扱います。同じIDを除外し、共通の正のタグがあり類似度が0より大きい候補を、高い順・同点はIDの小さい順に1件選びます。理由は両者のスコア積が大きい共通タグを最大2件表示します。点数は味覚の一致確率ではありません。

空カタログは登録準備の案内、候補なし・タグ不足・1銘柄のみの場合は比較準備中の案内になります。商品詳細の `similarIds` は従来の編集者指定を維持し、ホームの比較選定とは独立しています。DBスキーマの変更は不要です。

候補を編集したら再起動してください。外部設定は `--app.major-sake=file:/絶対パス/major-sake.json` で指定できます。同じ名称の重複、必要情報の欠落、不正なHTTPSの根拠URLは起動時にエラーになります。

## 検証

`./gradlew test` でタグの近さ、本人除外、候補限定、同点、タグ不足、空・1件カタログ、匿名でのガイド表示、ホームの比較と出典を確認します。Node.jsで `node --test src/test/js/*.test.cjs` を実行し、既存のトピック等も検証します。ブラウザでPC・スマートフォン幅と目次・詳細からの導線を確認します。
