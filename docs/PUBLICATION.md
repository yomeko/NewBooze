## 追加した案内と設定

/about、/contact、/privacy、/external-transmissionは登録前にも閲覧できます。研究目的、終了方針、扱う情報と利用目的、公開レビューの範囲、退会、メール配送とブラウザの外部接続を説明します。

設定は環境変数、またはGit管理外のローカル設定に指定します。値を入れずに起動すると、運営者名は未定、窓口は準備中になります。

```properties
# 公開する名称と連絡先が確定してから設定する。空欄は未設定。
app.public.operator-name=
app.public.contact-email=
```

対応する環境変数は `SITE_OPERATOR_NAME` と `SITE_CONTACT_EMAIL` です。再起動で反映します。運営者名は改行を含まない120文字以内、問い合わせ先は通常のASCIIメールアドレス形式です。メールリンクへ別の宛先・件名などを混入できる値は拒否します。不正な設定は値自体をログへ出さずに起動エラーとします。未設定の問い合わせ先にはmailtoリンクを出しません。設定済みのリンクは利用者のメールアプリを開くだけで、サイトから問い合わせメールを送る機能ではありません。

Google Fontsへの接続先はfonts.googleapis.comとfonts.gstatic.comです。認証・再設定メールはサーバーから設定SMTPへ渡し、ブラウザのフォント取得とは区別しています。現在のコードには広告・アクセス解析の外部スクリプトを追加していません。公開環境のサーバー・メール配送事業者・アクセスログの扱いは、運用先を決めてから案内を更新します。

10銘柄の照合結果・公式出典・確認日は [商品情報の台帳](../data/catalog-publication-audit.csv) と [商品詳細の説明](../data/SAKE_PAGES.md) に記録しました。

- 出羽桜 桜花吟醸：詳細JSONに720ml・税込1771円と公式URLを追加。
- 八海山 特別本醸造：公式URLを追加。税抜資料から計算した税込価格を、公式掲載の税込価格として追加していません。
- タイプ・年度・容量が特定できない商品や、公式本文を取得できなかった情報は未確認として記録。既存の容量不明の参考価格は別容量の価格で上書きしていません。

商品写真は [公開承認台帳](../src/main/resources/data/product-image-publication.json) で個別に管理します。現在の7候補は公開利用の根拠を確認できていないため全件未承認です。DBの元URLと写真ファイルは保持し、表示モデルへ渡すURLだけを制御します。写真なしで利用できるため、写真の許諾が取れなくても無断使用して埋める必要はありません。

承認は銘柄ID・名称・URLの完全一致に加え、権利者、利用根拠URL、確認日、利用条件が必要です。公式サイトに画像があることだけでは承認しません。管理画面でアップロードした写真も自動承認しません。プロフィール画像とサイトアイコンはこの台帳の対象外です。詳細は [商品写真の公開利用の確認](../data/PRODUCT_IMAGE_PUBLICATION.md) を参照してください。

## 2026年10月21日の実DB確認

接続先はローカルの `issho_no_deai`、MariaDB 10.11.19です。既定のnewbooze DBや別環境への適用は確認していません。

- 10銘柄のIDと名称が本文JSONと一致。
- sake_page_detailsの上書きは0件で、今回のJSON更新が表示に利用される状態。
- sake.image_urlは全10件NULL。リポジトリの7候補が実DBに登録済みだとは扱わない。
- sakeとsake_page_detailsをローカルへバックアップ後、catalog_publication_corrections.sqlを適用。名称・産地・旧16.0%を照合し、獺祭45の1行だけが15.0%に変更。他商品の値、価格、画像URL等は不変。
- 作成SQLによる初期化・DBの削除・復元は実施していない。バックアップや会員情報をGitへ追加していない。

別環境では、接続先とバックアップ、商品名・産地・旧値を確認してから [差分SQL](../data/catalog_publication_corrections.sql) を適用します。管理画面に保存した紹介文がある環境では、本文JSONより優先されるので内容を別途確認します。
