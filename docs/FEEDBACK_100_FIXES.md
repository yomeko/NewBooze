# 百人登録フィードバックへの対応

対応・検証日：2026年10月15日。対象はNewBoozeのソースとローカル環境。公開環境へのデプロイ確認ではない。

| 指摘 | 今回の対応 |
|---|---|
| スマホ検索のページ送り | スマホ向けnavの非表示・位置指定をヘッダー内に限定。検索のページ送りを表示し、折り返し・現在ページの読み上げに対応。 |
| 検索条件の保持 | 現在値を表示するキーワード欄を検索フォームに追加。並べ替え・価格帯変更・ページ移動へ条件を引き継ぎ、条件解除リンクを追加。価格帯は参考価格と明記。 |
| 登録のエラー案内 | UTF-8で72バイトを超えるパスワードをハッシュ化・保存前に拒否し、登録画面に理由を表示。上限と日本語の目安を案内し、設定画面のパスワード変更にも同じ検証を適用。 |
| 再診断の意味 | 今回出たタグだけを更新し、出なかった過去タグを残す既存仕様を維持。診断前・結果・マイページで今回の結果と保存された傾向の違いを説明。 |
| スマホ設定画面 | 戻るリンクにも適用されていたnavの非表示指定を解消。 |
| 準備中の入口 | 未完成の9メニューに準備中を表示。プライバシーポリシーを専用の公開ページにし、登録前の入口・扱う情報・利用目的・公開範囲を用意。 |
| 購入判断の情報 | 詳細に酒種・産地・度数・容量別価格を追加。容量・価格・度数の未確認値は推測せず、未確認と表示。 |
