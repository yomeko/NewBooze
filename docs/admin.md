# 管理画面

既存DBでは起動前に `data/admin_schema.sql` を実行してください。新規DBの作成SQLにも admin 列を含めています。

管理者は `ADMIN_EMAIL` と `ADMIN_PASSWORD` を環境変数で明示した場合だけ、未登録なら作成します。パスワードは16文字以上・UTF-8で72バイト以内にし、他サービスと使い回さないでください。パスワードはBCryptで保存し、既存アカウントは上書きも管理者への昇格もしません。環境変数が未設定なら管理者を自動作成しません。

ログイン画面に設定した管理者IDとパスワードを入力すると `/admin` に移動します。初回作成後は `ADMIN_PASSWORD` を実行環境から外せます。

旧版で作成された固定初期パスワードの管理者は、認証時に拒否されます。既存DBのアカウントは自動変更しません。別の管理者IDを上記の環境変数で作成し、DB管理者が旧アカウントのパスワード変更または停止を実施してください。更新時にアプリを再起動して、旧版のメモリ内ログインセッションも失効させてください。認証情報はGitやチャットに貼り付けないでください。

- `/admin/sake/new`: 銘柄名、酒種、地域、度数、価格、説明を登録します。
- `/admin/users`: ユーザー名の部分一致検索と30件ずつの一覧表示ができます。

一般の新規登録は引き続き `/signup` から行い、管理者権限は付与されません。

商品画像は登録フォームでJPEG・PNG（5MB以下、2000万画素以下）を選択できます。保存後は日本酒詳細ページに表示されます。保存先は `./uploads/sake` で、再起動後も保持されます。`app.sake-image-directory` で変更可能です。運用時はこのフォルダもバックアップしてください。DBスキーマの追加変更は不要です。

## 商品詳細の形式で登録

商品画像・酒蔵名・銘柄名・紹介文、味わいタグ、味わい・香り、こんな人におすすめ、おすすめの飲み方、合う料理、公式サイト・公式購入先を商品詳細と同じ順序で入力できます。箇条書きの情報は1行1項目で入力します。銘柄名と酒種のみ必須です。空欄の紹介項目は表示しません。評価・コメントは利用者が投稿する情報のため、このフォームには含めません。

既存DBは起動前に `data/sake_page_details_schema.sql` を反映してください。管理画面で登録した詳細情報はDBへ保存し、既存のJSONデータを変更しません。酒蔵名は既存の酒蔵と照合し、未登録の名前は新規に保存します。タグ選択は既存の検索・診断にも使われます。
