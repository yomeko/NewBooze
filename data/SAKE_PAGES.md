# 日本酒詳細ページの編集方法

`src/main/resources/data/sake-pages.json` が共通ページの補完用表示データです。管理画面で保存した `sake_page_details.detail_json` があれば、そちらを優先します。
HTMLを銘柄ごとに作成する必要はありません。変更後はアプリを再起動してください。
配布用JARを使う場合は再ビルドするか、`--app.sake-pages=file:/絶対パス/sake-pages.json` で外部ファイルを指定します。

## 初回セットアップ

更新版を起動する前に `data/sake_reviews_schema.sql` を newbooze DBで実行してください。
既存テーブルを消さず、評価用テーブルだけを追加します。この作業環境には適用済みです。
続けて `data/public_reviews_schema.sql` を実行してください（この作業環境には適用済み）。
評価は1人・1銘柄につき1件を更新します。「みんなに公開する」を選ぶと表示名・星・コメント・更新日が公開されます。
従来の非公開レビューは移行後も非公開です。新規投稿フォームでは公開が初期選択され、保存前に変更できます。
公開レビューは10件ずつ表示し、新しい順・評価が高い順・低い順に並べ替えできます。
検索一覧は平均評価の高い順・低い順・件数順に対応。非公開レビューは集計対象外、未評価銘柄は最後になります。
平均評価が同じ場合は評価件数が多い銘柄を優先します。
お気に入りは既存のマイページと共通です。

## データの書き方

### 商品紹介の記入フォーマット

<!-- 診断タグは本文JSONの味わいとは別に、共通DBへ登録するための記入項目。 -->

新しい商品を紹介する際は、以下を埋めてください。

```text
商品ID：
商品名：
酒造名：
紹介文（約100文字・最大160文字）：
診断タグ（診断と共通のタグ名）：
  例：甘口（強さ4）、フルーティー（強さ5）、軽快（強さ3）
味わい：
香り：
おすすめの飲み方：
合う料理：
おすすめしたい人：
商品写真URL：
公式URL：
公式購入先URL：
似ている商品のID：
```

診断タグは紹介文の直下に `#フルーティー #甘口 #軽快` の形式で、強さの高い順に表示されます。クリックすると同じタグの商品を検索できます。検索欄への `#甘口`・`＃甘口` の入力にも対応します。

タグはJSONには追加せず、診断と共通のDBに登録します。初期タグは **フルーティー・旨口・辛口・軽快・濃醇・酸味・甘口** です。自由記述の「味わい」と区別し、実際に登録されたタグ名を記入してください。DBには `#` を付けない名前を保存します。

既存タグを商品に設定するSQLの記入例です。商品とタグを登録した後に、接続先のDBで実行してください。`@product_id` とタグ・強さを対象商品に合わせて変更します。強さは1〜5を目安にし、根拠を確認して設定してください。

```sql
-- 対象商品のIDを指定し、DBに登録済みのタグ名を使う（#は付けない）。
SET @product_id = 1;
INSERT INTO sake_tags (sake_id, tag_id, score)
SELECT @product_id, id, 4 FROM tags WHERE name = '甘口'
-- 同じ商品・タグの組み合わせが既存の場合は、特徴の強さだけを更新する。
ON DUPLICATE KEY UPDATE score = VALUES(score);
```

このSQLは指定タグの追加・強さの更新を行います。不要なタグは `sake_tags` の対象商品・タグの行を削除してください。未登録タグの追加や診断選択肢との関連付けは [TAGS.md](TAGS.md) を参照してください。

### ページ本文のJSON

ファイル全体は配列です。以下のオブジェクトを銘柄ごとに追加・編集します。
`id` はDBの `sake.id` と合わせてください。新銘柄は既存の検索・診断との連携のためDBにも登録が必要です。
JSONの追加だけでDBの検索対象が増えるわけではありません。
`name` は詳細ページでの表示名で、空欄ならDBの商品名を使います。検索画面の名前・価格は従来のDBを参照します。

```json
{
  "id": 1,
  "name": "銘柄名",
  "introduction": "自分の言葉で約100文字の紹介文を入力します。",
  "brewery": "酒造名",
  "taste": ["やさしい甘み", "すっきり"],
  "aroma": ["華やか"],
  "prices": [{"volume": "720ml", "yen": null}],
  "drinking": ["冷やして楽しむ"],
  "food": ["確認済みのおすすめ料理"],
  "recommendedFor": ["どんな人におすすめか"],
  "officialUrl": "",
  "similarIds": [],
  "purchaseLinks": []
}
```

- 文字列は `""`、一覧は `[]`、不明な金額は `null` で空欄として扱います。項目の省略も可能です。本文等の空欄は省略し、基本情報の容量・価格は下記の規則で未確認と案内します。
- 紹介文は約100文字を目安にし、最大160文字です。既存の短い紹介文もそのまま使用できます。
- `yen` は税込の正の整数。容量だけ、価格だけでも表示できます。
- `purchaseLinks` は `{"label":"公式ショップ","url":"https://…","official":true}` の配列。
- `official:true` のリンクを先頭に表示します。公式の販売先であることを確認して設定してください。
- 外部URLは `https://` のみ。無効なリンクや重複IDは起動時にエラーになります。
- `similarIds` は登録済み銘柄のID配列。存在しないID、自分自身、重複したIDは画面に出ません。
- `food`・`recommendedFor`・`similarIds` は編集者が根拠を確認して設定する項目です。
- 商品写真はDBの `sake.image_url` と公開承認台帳が銘柄ID・名称・URLで一致し、利用根拠が揃った写真だけを表示します。登録方法と承認手順は `data/SAKE_IMAGES.md` と `data/PRODUCT_IMAGE_PUBLICATION.md` を参照してください。JSONに画像項目を追加する必要はありません。未登録・未承認の場合は詳細の写真枠を表示しません。本文はHTMLとして解釈せず、テキスト表示します。
- JSONに未登録の既存銘柄も、DBの名前・酒造名で詳細ページを表示できます。

## 基本情報と容量別価格の表示

詳細ページの基本情報にはDBの酒種・産地・登録されたアルコール度数を表示します。度数が0以下なら未確認と表示し、登録情報の参考値であることを案内します。`prices` があれば容量別の税込価格を表示し、容量が空なら「対象容量：未確認」、金額が空なら「価格：未確認」と表示します。`prices` が空なら、容量を未確認とし、DBの価格が正なら対象容量未確認の参考価格を表示します。DB価格も未登録なら価格を未確認と表示します。

価格は記載された容量のもので、販売店・時期・容量によって異なり、検索一覧の参考価格と異なる場合があることを案内します。検索・並べ替えは引き続きDBの参考価格を使います。未確認の容量や価格を推測で補わず、購入前に公式サイト・商品ラベルで最新の仕様を確認する案内を付けます。今回の表示改善ではDB値やスキーマを更新していません。

### 既存DBへの獺祭の度数訂正

[catalog_publication_corrections.sql](catalog_publication_corrections.sql) は、名前が「獺祭 純米大吟醸45」、産地が「山口県」、旧度数が16.0%の行だけを15.0%へ訂正します。ID固定ではありません。ほかの銘柄・度数の編集済み値・参考価格・会員データを変更しません。再実行時は旧度数に一致しなければ0件更新です。

適用前に接続先・対象行・バックアップを確認してください。`create_issho_no_deai.sql` は新規作成用であり、この訂正のために既存DBへ実行しないでください。SQL内の `SELECT` と `updated_rows` で前後の値と更新件数を確認します。別環境への適用は文書の追加だけでは完了しません。

2026年10月21日のローカル実DB確認では、接続先 `issho_no_deai`（MariaDB 10.11.19）の10銘柄のID・名前が本文JSONと一致し、詳細紹介のDB上書きは0件でした。商品テーブルと詳細テーブルのバックアップ後に差分SQLを適用し、獺祭45の度数1件だけが16.0から15.0に変わり、他銘柄・価格・画像URL等は変わっていないことを確認しました。画像URLは全10件ともNULLでした。既定の `newbooze` DBや別の環境への適用を確認した記録ではありません。今回の検証結果と公開前の残項目は `docs/PUBLICATION.md` を参照してください。
